Core equations
Roof cells: dVᵢ/dt = qrain,ᵢ + ΣQj→i − ΣQi→j − Qnormal,external,ᵢ − Qoverflow,ᵢ Normal drainage: Qnormal,external = verified project input (no gravity/siphonic network calculation in this tool) Lateral sheet flow: q = b/n · h^(5/3) · sqrt(|Δη|/L) η = z0 − w + h Structural feedback: qwater = ρg h EI′ wₓₓₓₓ = qwater (one-way) D ∇⁴w = qwater (two-way) zroof = z0 − w Tank: dVₜ/dt = Qto_tank − Qsewer − Qreuse − Qoverflow Circular emergency opening: Q = Cd·N·∫ b(y)√(2g(H−y))dy Rectangular emergency opening: Q = Cd·N·b·(2/3)√(2g)·[H^(3/2) − (H−a)₊^(3/2)] Wall rain: Rwall = Rh · k · U/vfall · max(0, −dwind·nwall)
