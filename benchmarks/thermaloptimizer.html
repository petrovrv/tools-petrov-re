Expert family priors / site sources

Terminal priors are editable screening assumptions. Ground/source-water families are suppressed unless complete explicit source records are supplied. Borefield geometry/search choices and Rb, water-temperature profile and HX geometry are never inferred.

Specify exactly one source-water temperature input: hourly series, project profile reference, or monthly fallback. Hourly length must exactly match the 8760/8784 project calendar.

No physical threshold is inferred unless an explicit bracket is supplied. Each trial reruns both candidates annually and re-screens source physical feasibility.
